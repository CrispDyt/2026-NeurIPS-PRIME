# 代码整理与复现差异

已按照 Downloads 中的 `2026_NIPS_PRIME.pdf`，从 NIPS 和 Entropy 中整理论文相关代码。旧目录保持原样；新仓库包含三个主系统的训练、评估、60个选定模型、固定输入数据、原始结果，以及基线、消融、绘图和耗时实验的相关实现。

## 可以直接做的事

- 运行 `python scripts/build_tables.py`，重新统计表2、表3和附录的每个seed、mean/std、median、Q25/Q75，并输出CSV和LaTeX。
- 运行三个系统的 `evaluate.py`，用保留的模型重新评估；KS–MSE seed123123使用此前独立补训后的正确模型。
- 运行 `train.py`，从头训练四种目标。PRIME在主表中指保留DIM的完整方案；PRIME-only在消融中单列。
- 按各项说明运行异构基线、周期/截面/损失消融、参数敏感性及计时代码。

## 整理时发现的实质差异

| 项目 | 实际记录 | 对论文/复现的影响 |
|---|---|---|
| Lorenz PRIME seed13532文件夹 | 模型内部记录seed13531，且候选比例、landmark数量、stage2权重不同 | 不能称为与另外4个seed完全相同的配置；新训练不会暗中改seed |
| KS DIM+MSE seed13531文件夹 | 模型内部记录seed200 | 保留原表身份以便追溯，但必须说明元数据差异 |
| KS部分PRIME模型 | 训练总步数、warm-up和权重不同；当前notebook未保留全部旧损失实现 | 旧模型可评估，所有旧训练过程不能保证逐步重现 |
| 圆柱绕流PRIME | seed123123123使用MSE系数2，其余4个使用0；seed13532训练较短 | 不是严格统一的五种子训练配置 |
| 圆柱绕流网络 | MSE为2个隐藏层，另外三种模型为3个隐藏层 | 与“所有目标使用相同骨干网络”的表述不完全一致 |
| 圆柱绕流DRTD截面 | 代码顺序为通道6、4、5；论文文字为5、4、6 | 应核对截面文字/编号，不能简单交换统计结果假装修正 |
| DIM损失 | 多个主实验源代码使用energy distance，而非统一Sinkhorn | 需要核对方法/实现细节的文字描述 |
| 表4与图9 | 使用不同的PRIME模型 | 已分别保留，并在命令默认值中区分 |
| 表6 | 两组控制实验的PRIME参照与评估环境不同 | 原始行已保留，但不能当作同一设置下重跑的一张表 |
| 表14 DRTD标准差 | 源代码在3个截面之间计算标准差，表题则写30个rollout | 需要核对该列统计口径的描述 |
| 表19耗时 | 原计时脚本与精度实验的某些目标/设置不同 | 可以复现原计时逻辑，不宜直接称为精度模型的统一耗时比较 |

详细来源及命令见英文的系统说明和 [覆盖清单](paper_coverage.md)。以上差异未通过改名字、替换数值或补造模型来消除。

已进行短训练、源码一致性、部分完整长度评估及绘图检查；没有把所有模型、所有seed和全部消融重新训练一遍。CPU测试通过只说明程序可以运行，不能保证混沌长轨迹与CUDA历史结果逐位一致。
