# Third-party code and provenance

The optional cylinder simulator and KS spectral stepping code derive from Felix Köhler's [Machine Learning and Simulation](https://github.com/Ceyron/machine-learning-and-simulation), copyright (c) 2021 Felix Köhler, MIT license. The complete upstream notice is retained in [licenses/Ceyron-MIT.txt](licenses/Ceyron-MIT.txt); its source is [LICENSE.txt](https://github.com/Ceyron/machine-learning-and-simulation/blob/main/LICENSE.txt). The local cylinder simulator's original copyright header is preserved. KS-specific attribution also appears in `experiments/ks/THIRD_PARTY.md`.

The simulator parameters, sensor extraction, noisy observation splits and command-line interfaces contain adaptations from the NIPS/Entropy experiments. This upstream license does not establish release terms for the paper authors' other code, datasets, or trained weights. No project-wide license file was found during curation.

Each `reference/*/provenance.json` records the original local source and selected asset hashes. The supplied manuscript PDF is used only to map experiments to tables and figures and is not redistributed in this repository.
